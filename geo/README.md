# Globe land geometry

`land-110m.json` is the 1:110 million land dataset from Natural Earth.

- Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
- License: public domain, https://www.naturalearthdata.com/about/terms-of-use/

Used as a decorative land mask, without political boundaries. The globe is generated locally with Three.js; no external map services are needed at runtime.
